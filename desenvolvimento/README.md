# Desenvolvimento experimental

Esta pasta é reservada para adaptações futuras.

A implementação validada da Etapa 200 permanece em
`firmware/etapa200-original/`.

Não alterar os arquivos originais para experimentar
novas configurações de SPI, PIO ou emulação.

Os experimentos serão criados em diretórios separados,
com novos nomes e resultados próprios.
